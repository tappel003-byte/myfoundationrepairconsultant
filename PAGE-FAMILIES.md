# MFRC page families

One look per family. Do not mix templates across families.

## Orientation pair — same look
- `/start-here`
- `/how-the-industry-has-changed`

Gray banner. Glance strip optional. Topics as a simple list, not a gray dump. Questions / sections as clean accordion rows. White cards with hover lift if used. Teal text links.

## Repair methods — same look
- `/micropiles` (canonical)
- `/helical-piers`
- later: push piers, compaction grouting, foam, other methods

Gray banner. Glance strip. Topic box with chile-red left edge. Accordion body. Condition cards white with hover. No Under Construction cards on the live page.

## Technical reference hubs — same look
- `/foundation-types`
- `/material-behavior`
- `/common-signs`

Informational hubs. Same chrome as methods is fine (banner + glance + topics + accordions). Not a blog.

## Dictionary — its own animal
- `/foundation-repair-dictionary`

A-Z entries. Heavy cross-links. Not a long essay page.

## Knowledge Center indexes — same look
- `/educational-articles`
- `/industry-articles`
- `/all-articles` is a quiet file cabinet, not the front door

Accordion topic rows with article counts. Teal titles inside the row. Arrows. Like the live Squarespace Industry Articles page.

## Knowledge Center articles — same look (paper)
- everything under `/all-articles/*`

Narrow column. Gray banner with title. Body reads like a paper, not a blog post. Teal links. No sales disclaimer footer.

## Regional pair — same look
- New Mexico: `/foundation-behavior-in-new-mexico`, `/new-mexico-soil-conditions`, `/investigate-further`
- Arizona: `/foundation-behavior-in-arizona`, `/know-before-you-sign`

NM and AZ pages share one regional template. Investigate Further may contain the only company links (TLS, Sandia Geo, Foundation Repair Advocate).

## Shared chrome
- Header: chile logo + hover dropdowns that close on mouse leave
- Link color: logo teal `#2d9499`
- Door accent: thin chile red `#c4160d` on glance / topic box only
- Footer: quiet. No manifesto. No extra nav.
